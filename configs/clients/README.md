# Клиентские конфиги

Каждый файл `{client_id}.yaml` содержит **только переопределения** относительно системного дефолта `configs/config.yaml`.

Пустой файл или отсутствие файла = используется системный дефолт целиком.

## Правила

- Указывайте **только то, что отличается** от дефолта
- Системный `config.yaml` **никогда не трогайте** под конкретных клиентов
- Валидация запускается автоматически при сохранении

## Пример

```yaml
# configs/clients/acme.yaml
model:
  horizon: 28
features:
  weather:
    enabled: true
    latitude: 59.93
    longitude: 30.32
  holidays:
    country: RU
```
