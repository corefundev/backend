# Format: one domain per line, lowercase, no port, no @.
# Lines starting with # are comments; blank lines ignored.

# This file is loaded at process start by src/auth/disposable_domains.py
# and consulted on every /auth/signup request. Edits require a process

#     scripts/update_disposable_list.sh

# of casual disposable-email signups in 2024-2026. The full list at
# https://github.com/disposable/disposable-email-domains has ~12 000
