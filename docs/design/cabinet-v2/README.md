Замечания соответствия:
- Брендинг Sprosly на прототипах — применяется ПОСЛЕ переезда (MIGR-1 #424); до него shell собирается с текущим брендом, свап логотипа — атомарно при миграции.
- «Уровень сервиса» = model.service_level (τ∈[0.5,0.95]); подпись N:1 = τ/(1−τ), округлённо.
- «Страховой запас» = Σquantile_τ − Σточечного прогноза окна; «Заказ» = прогноз + запас − остаток (остаток из stock-колонки клиента; нет колонки — слагаемое опускается и колонка «—»).
