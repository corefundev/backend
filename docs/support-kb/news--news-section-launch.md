# В сервисе появился раздел «Новости»

Теперь все обновления сервиса публикуются здесь.

**Что будет в ленте:**

- релизы и новые возможности;
- улучшения точности прогнозов;
- уведомления о плановых работах;
- советы по работе с данными.

Важные объявления дополнительно приходят в колокольчик уведомлений в кабинете.
