# Глоссарий: Рекомендуемый заказ

**Рекомендуемый заказ** — количество товара, которое сервис советует заказать на период закупки.

Формула: **Заказ = прогноз спроса за окно + страховой запас − текущий остаток**. Остаток берётся из колонки `stock` ваших данных (если её нет, вычитание не выполняется). Результат не бывает отрицательным и округляется вверх до целых штук. Рекомендацию можно изменить вручную перед выгрузкой заказа.
