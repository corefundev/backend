# Как выгрузить заказ для 1С

1. Откройте раздел **Автозаказ** и выберите датасет.
2. Проверьте окно заказа (по умолчанию 14 дней) и уровень сервиса.
3. При необходимости скорректируйте рекомендованные количества вручную.
4. Нажмите **«Выгрузить заказ для 1С»** — скачается CSV-файл.

Формат файла: кодировка UTF-8 с BOM (корректно открывается в 1С и русском Excel), разделитель «;», колонки: SKU; Остаток; Спрос (прогноз); Страховой запас; К заказу; Мин (p10); Макс (p90); Дней в окне; Дней с рекомендацией. Количество к заказу округлено вверх до штук.

Если прогнозов ещё нет, сервис сообщит «Прогнозов ещё нет — обучите модель».
