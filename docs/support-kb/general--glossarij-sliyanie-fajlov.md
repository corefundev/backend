# Глоссарий: Слияние файлов («новый файл побеждает»)

**Слияние файлов** — правило, по которому новый файл объединяется с уже загруженной историей датасета: если данные пересекаются по паре «SKU + дата», **побеждает новый файл** — пересекающиеся дни заменяются его значениями.

Это даёт простой способ ретро-исправлений: заметили ошибку в данных месяца — перезагрузите исправленный файл этого месяца. После каждой докладки показывается отчёт «+N · заменено M» (сколько строк добавлено и сколько заменено).
