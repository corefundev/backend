# Как обновлять данные

Чтобы прогноз учитывал свежие продажи, регулярно обновляйте данные.

## Главное правило

Загружайте **полную историю целиком** — с самого начала и по последний день, а не только «новые» строки. Система работает с последней загруженной историей как с единым целым: так исключаются дыры и расхождения на стыках.

## Рекомендуемый ритм

- раз в месяц — для большинства;
- раз в неделю — если ассортимент быстро меняется.

После каждого обновления: «Подготовить» → «Запустить обучение». Прогноз пересчитается на свежей истории.
