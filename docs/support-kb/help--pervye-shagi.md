# С чего начать: путь до первого прогноза

Путь от пустого аккаунта до готового прогноза занимает четыре шага.

1. **Загрузите данные.** Раздел «Загрузки» → файл CSV или Excel с историей продаж. Что должно быть в файле — в статье «Как загрузить данные о продажах».
2. **Подготовьте данные.** После проверки файла нажмите «Подготовить» — система сама сопоставит колонки и покажет предпросмотр результата.
3. **Запустите обучение.** Раздел «Обучение» → «Запустить». Модель обучается на вашей истории; по завершении придёт уведомление.
4. **Откройте «Прогнозы».** Готовый прогноз можно смотреть по каждому SKU и выгружать.

Чем длиннее и чище история продаж, тем точнее прогноз. Рекомендуем минимум год данных — так модель видит сезонность.
