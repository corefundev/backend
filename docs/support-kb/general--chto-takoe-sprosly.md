# Sprosly: что это, какие задачи решает и чем отличается подход

## Одним абзацем

Sprosly — облачный сервис прогнозирования спроса по SKU для розницы и e-commerce. Вы загружаете историю продаж (CSV или Excel), сервис обучает модель машинного обучения на ваших данных и выдаёт прогноз спроса по дням для каждого товара, а также рекомендации, сколько заказать. Без собственного аналитика и без своей ML-инфраструктуры.

## Для кого

- **Розничные магазины и сети** — прогноз спроса по товарам для планирования закупок.
- **Интернет-магазины и продавцы маркетплейсов** — планирование остатков с учётом промо и сезонности.
- **Склады, производство и опт** — прогноз отгрузок, снижение излишков и дефицита.

## Какие задачи решает

1. **Прогноз спроса** — сколько единиц каждого товара будет продано завтра, за неделю, за две недели и дальше (горизонт зависит от тарифа). Прогноз вероятностный: кроме основного числа даётся диапазон p10–p90.
2. **Автозаказ** — рекомендация, сколько заказать на период закупки: прогноз спроса + страховой запас − текущий остаток, с выгрузкой заказа в CSV для 1С.
3. **Контроль качества прогноза** — у каждой модели измеряется честная точность (WMAPE, MASE, «точность для заказа»), и вы видите, насколько модель лучше наивного прогноза.

## Чем отличается подход

- **Обучение на данных клиента.** Модель строится персонально на вашей истории продаж — данные разных клиентов изолированы и не используются для чужих моделей.
- **Честная метрика качества.** Точность измеряется на данных, которые модель не видела при обучении: последние недели истории скрываются, модель их предсказывает, прогноз сверяется с фактом.
- **«Точнее наивного».** Сервис всегда сравнивает модель с наивным прогнозом («как вчера» / «как в этот день неделю назад»). Если модель не лучше — вы это увидите, а не узнаете постфактум по излишкам на складе.
- **Гейт качества.** Новая модель после переобучения публикуется только если она не хуже действующей — случайно испортить прогноз переобучением нельзя.
- **Простота.** Путь «файл → прогноз» занимает минуты и не требует настройки: колонки сопоставляются автоматически, обучение запускается одной кнопкой.
