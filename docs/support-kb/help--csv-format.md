# Формат CSV: обязательные колонки date/sku/sales, опциональные price/promo/stock

Сервис читает продажи из CSV-файла. Вот какие колонки нужны и какого они должны быть формата.

## Обязательные колонки

Файл **должен** содержать три колонки:

**date** — дата продажи

- Формат: YYYY-MM-DD (например, 2025-01-15)
- Без времени (только дата)
- В хронологическом порядке (старые дни сверху, новые снизу)

**sku** — уникальный код товара

- Это может быть артикул, штрихкод, внутренний код вашей системы
- Текст (не число) — сохраняются все символы, включая ведущие нули
- Каждый SKU представляет один товар
- Разные склады или магазины считаются разными SKU (если нужны отдельные прогнозы)

**sales** — количество проданных единиц

- Число (целое или с точкой: 100 или 100.5)
- Не может быть отрицательным (если товар вернули, вычтите из sales этого дня)
- Если товар в день не продавался, укажите 0

## Опциональные колонки

Эти колонки помогают модели работать точнее, но не обязательны:

**price** — цена товара в этот день

- Число (рубли, копейки через точку)
- Если цена менялась, укажите актуальную цену для дня
- Помогает модели видеть, как цена влияет на спрос

**promo** — был ли промо (акция) в этот день

- Значение: 0 (нет) или 1 (да)
- Или: false / true
- Помогает модели видеть скачки спроса на фоне акций

**stock** — остаток на полке в конце дня

- Число (сколько товара осталось после продажи)
- Помогает модели понять, не было ли ограничения по наличию (если товар распродан, спрос может быть выше)

## Пример файла

```
date,sku,sales,price,promo,stock
2024-11-01,ART001,10,250.50,0,45
2024-11-02,ART001,12,250.50,0,33
2024-11-03,ART001,25,200.00,1,8
2024-11-04,ART001,8,250.50,0,0
2024-11-05,ART001,0,250.50,0,15
2024-11-01,ART002,5,500.00,0,20
2024-11-02,ART002,4,500.00,0,16
```

Файл может быть выгружен из 1С, Excel, Google Sheets или любой другой системы, если вы сохраните его в CSV.

## Типовые ошибки при выгрузке

**Неправильный формат даты**

- Вместо YYYY-MM-DD используете DD.MM.YYYY (например, 15.01.2025)
- Дата с временем (2025-01-15 14:30:00)

Решение: переформатируйте дату в системе перед выгрузкой или исправьте в Excel.

**SKU как число**

- В 1С код товара содержит ведущие нули (00123), но при выгрузке они теряются
- Это приводит к неправильному сопоставлению товаров

Решение: при выгрузке из 1С убедитесь, что SKU сохраняется как текст. В Excel выберите колонку и установите формат "Текст".

**Отсутствие данных за целые дни**

Дни без продаж можно не включать в файл — система сама учтёт пропущенные дни как нулевой спрос. Но если вам удобнее выгружать строки с sales = 0 за каждый день, это тоже корректно.

**Дублирование**

- В файле одна и та же дата + SKU появляется дважды

Решение: проверьте выгрузку в 1С (может быть опция "убрать дубли" или нужно сгруппировать по дате/SKU).

**Пустые ячейки в обязательных полях**

- Date, SKU или Sales пусто для какой-то строки

Решение: удалите эту строку или заполните пропуск (для sales используйте 0).

## Размер файла

Сервис принимает файлы размером до 50 МБ. Если файл больше, сначала отфильтруйте данные:

- Оставьте только нужные товары (не весь каталог)
- Оставьте только нужный период (последние 1–2 года)
- Если храните несколько магазинов в одном файле, разделите по магазинам

## Как создать CSV из Excel

1. Откройте таблицу в Excel
2. Проверьте, что колонки названы правильно (date, sku, sales…)
3. Выберите **Файл** → **Сохранить как**
4. Выберите формат **CSV (разделитель — запятая)**
5. Нажмите **Сохранить**

На Mac это может быть **Сохранить как** → **Формат: CSV UTF-8**.

Теперь файл готов к загрузке в сервис.
