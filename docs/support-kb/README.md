# Support-KB corpus (SUP-1, эпик #503)

Нормализованный источник знаний для AI Support Assistant (RAG) и —
независимо от бота — ревизионная копия клиентской документации.
Собран 2026-07-19 из живой Помощи, новостей, кода (тарифы, лимиты,
ошибки, механики) и лендинга; каждый файл несёт frontmatter
(source/origin/title/category/as_of).

- `_inventory.md` — реестр файлов
- `_gaps.md` — 28 вопросов клиентов без ответа + противоречия
  опубликованной Помощи с кодом (см. issues #512/#513)
- `_stats.md` — покрытие

Правило: факты выверяются по коду; при обновлении продукта корпус
обновляется тем же PR или задачей-хвостом.
