# Как загрузить данные о продажах

## Форматы

Поддерживаются **CSV** и **Excel**.

## Обязательные колонки

- **дата** — день продажи;
- **SKU** — артикул или код товара;
- **количество** — сколько штук продано за день.

Названия колонок могут быть любыми — при подготовке система сопоставит их автоматически.

## Рекомендации

- загружайте историю **минимум за год** — модель увидит сезонность;
- одна строка = один товар за один день;
- дни без продаж можно не включать — система учтёт их сама;
- не агрегируйте по неделям или месяцам: точность выше на дневных данных.
