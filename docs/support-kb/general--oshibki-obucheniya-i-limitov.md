# Ошибки при обучении и лимитах: что означают и что делать

**«Обучение уже выполняется» (код 409)**
На аккаунте в один момент времени может идти только одно обучение — на любом тарифе. Дождитесь завершения текущего запуска и повторите.

**«Пауза между обучениями» (код 429, тариф Free)**
На Free между запусками обучения действует пауза 12 часов. В сообщении указано, когда можно запустить снова («Тариф Free: следующий запуск доступен …»). Чтобы обучаться без пауз, перейдите на платный тариф.

**«В датасете N SKU — больше лимита тарифа (M)» (код 403)**
В данных больше товаров, чем допускает тариф (Free — 30, Start — 1 500). Сократите список SKU в файле или повысьте тариф.

**«В датасете ещё нет данных — доложите файл» (код 409)**
Обучение запускается только когда в датасете есть хотя бы одна влитая версия данных. Загрузите и подготовьте файл.

**«Текущая версия датасета не готова» (код 409)**
Версия данных ещё собирается или собрана с ошибкой. Дождитесь готовности версии; если статус не меняется — напишите в поддержку.

**«Очередь обучения недоступна — повторите позже» (код 503)**
Временная техническая проблема на нашей стороне. Повторите запуск через несколько минут.

**«Ограничение тарифа: лимит запросов прогноза» (код 429)**
Исчерпан часовой лимит запросов прогноза по API (Free — 100/час, Start — 5 000/час). В ответе указано, через сколько секунд можно повторить (заголовок Retry-After); уведомление об этом появляется в колокольчике не чаще раза в день.

**«Лимит датасетов вашего тарифа — N» (код 403)**
Достигнут лимит числа датасетов (Free — 1, Start — 3, Business — 10). Удалите неиспользуемый датасет или повысьте тариф.

**Письмо «Обучение модели было прервано»**
Запуск прервало обновление сервиса — ваши данные в порядке. Просто запустите обучение ещё раз: ограничение на повторный запуск снято автоматически.
