# Разделы кабинета Sprosly: Обзор, Данные, Прогнозы, Автозаказ, Настройки

Краткий путеводитель по разделам личного кабинета.

## Обзор

Главная страница кабинета: ключевые показатели — точность для заказа (14 дней), насколько модель точнее наивного прогноза, датасеты и сумма прогноза. Блок «Требует внимания» подсказывает следующее действие (обучить модель, подготовить файл, разобраться с ошибкой). Рядом — состояние датасетов (Актуальна / Отстаёт) и последние события.

## Данные

Список датасетов карточками: по каждому видно версию данных и версию модели, точность для заказа и нужное действие. Здесь же кнопка «+ Создать датасет» и «История подготовок» — журнал обработки загруженных файлов с фильтрами по датасету и статусу.

Страница отдельного датасета: период, файлы, строки, версия; кнопки «Доложить CSV» и «Обучить модель»; таблица файлов с колонкой «Слияние» («+N · заменено M»); блок «Модель» (предупреждение, если данные новее модели, и кнопка «Обучить на vN») и список версий данных с отметкой, на какой версии обучена модель.

## Прогнозы

Прогнозы по каждому SKU выбранного датасета. Окна суммирования — 7 / 14 / 28 дней (окно 28 дней — на тарифе Business). Показываются сумма прогноза, точность для заказа и модель; по каждому товару — прогноз на завтра, суммы за 7 и 14 дней, диапазон p10–p90 и динамика («+6% к прошлой неделе», «стабильно», «всплеск: акция?»). Таблицу можно сортировать по вкладу товара в общую сумму.

## Автозаказ

Рекомендации к заказу по выбранному датасету: остаток → прогноз спроса → страховой запас → рекомендуемый заказ (с возможностью изменить количество). Слайдер уровня сервиса с подписью «дефицит дороже хранения (N:1)». Внизу — формула «Заказ = прогноз + страховой запас − остаток» и кнопка «Выгрузить заказ для 1С».

## Настройки

- **Тариф** — текущий план и его возможности.
- **Аккаунт** — email, пароль, активные сессии.
- **API-ключ** — создание и отзыв ключа вида `sk_live_…`; ключ показывается один раз.
- **Уведомления** — управление по типам (Email / Выкл).

## Настройки модели

Отдельные настройки для каждого датасета; применяются **при следующем обучении**. Доступны: горизонт (7/14/28), уровень сервиса, календарь праздников (с выбором страны), сигнал валютных курсов (по умолчанию выключен). Здесь же — история обучений.
