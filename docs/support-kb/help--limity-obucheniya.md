# Лимиты обучения по тарифам

## Общие правила

- В один момент времени идёт **одно обучение** на аккаунт — параллельные запуски не ставятся в очередь, дождитесь завершения текущего.
- Месячных лимитов на количество обучений **нет**.

## Бесплатный тариф

Между запусками обучения действует пауза **12 часов**. Модель обучается по базовому профилю.

## Платные тарифы

Пауз между запусками нет. Обучение идёт по полному профилю — несколько моделей объединяются в ансамбль, что даёт более высокую точность. Сравнить тарифы можно в разделе «Апгрейд».
