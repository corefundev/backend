# Как докладывать свежие данные и переобучать модель

Чтобы прогноз учитывал свежие продажи, регулярно обновляйте данные (раз в неделю или месяц):

1. Выгрузите из учётной системы файл со свежим периодом (можно с запасом — пересекающиеся дни просто заменятся: «новый файл побеждает»).
2. На странице датасета нажмите **«Доложить CSV»**, загрузите файл, нажмите **«Подготовить»**.
3. После обработки файл вольётся в датасет: появится новая версия данных и отчёт «+N · заменено M».
4. Сервис покажет «данные новее модели» — нажмите **«Обучить на vN»** (или «Обучить модель»). Прогнозы пересчитаются на свежей истории.

Тот же приём работает для исправления ошибок задним числом: перезагрузите исправленный месяц — система заменит пересекающиеся дни и покажет, что изменилось.
