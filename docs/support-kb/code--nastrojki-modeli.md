# Настройки модели: что можно менять на каждом тарифе

Настройки модели задаются отдельно для каждого датасета и применяются **при следующем обучении** — чтобы изменения подействовали, переобучите модель.

## Free

Настройки модели недоступны — модель Notus работает со стандартными параметрами.

## Start

Доступны «бизнес-регуляторы» — настройки, понятные без знаний машинного обучения:

- **Горизонт прогноза** — на сколько дней вперёд строить прогноз (в пределах лимита тарифа).
- **Уровень сервиса** — стратегия страхового запаса для автозаказа (0.5–0.95).
- **Целевая функция обучения** — как модель штрафуется за ошибки (стандартный режим подобран под розничный спрос).
- **Праздники** — учитывать ли календарь праздников и какой страны.
- **Календарные признаки** — день недели, месяц и т.п.
- **Цена / промо / остатки** — использовать ли соответствующие колонки ваших данных как сигналы.
- **Погода** — учитывать ли погодные признаки.
- **Валютные курсы** — ежедневные курсы ЦБ РФ как дополнительный сигнал: USD, EUR, CNY, BYN, KZT. По умолчанию выключено; включайте, если ваш ассортимент чувствителен к курсу.
- **Окна тренда и лаги** — чувствительность модели к недавним изменениям спроса.

Тонкая настройка гиперпараметров (число деревьев, скорость обучения и т.п.) на Start недоступна.

## Business

Доступны все настройки, включая тонкие параметры обучения модели.

## Важно

- Изменение настроек само по себе не меняет текущие прогнозы — нужно переобучить модель.
- Исключение — **уровень сервиса**: его смена пересчитывает рекомендации автозаказа сразу, без переобучения.
