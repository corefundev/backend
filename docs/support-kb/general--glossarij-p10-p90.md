# Глоссарий: Диапазон p10–p90

**p10–p90** — доверительный диапазон прогноза: интервал, в котором спрос окажется с вероятностью 80%.

- **p10** — нижняя граница: лишь в 10% случаев спрос будет ниже неё.
- **p90** — верхняя граница: лишь в 10% случаев спрос будет выше неё.

Узкий диапазон — товар предсказуемый, модель уверена. Широкий — спрос волатильный, полагайтесь на диапазон и страховой запас, а не на одно число. Именно из p10–p90 считается страховой запас автозаказа.
