# Что происходит с файлом после загрузки: статусы

Каждый загруженный файл проходит фиксированный путь; текущий шаг виден в «Истории подготовок»:

1. **Загружен** — файл принят сервером.
2. **Проверка** — автоматический антивирусный скан (секунды). Если найдена угроза — файл удаляется со статусом «не прошёл проверку безопасности».
3. **Проверен** — файл чист и ждёт вашего действия: нажмите **«Подготовить»**. Без этого файл дальше не идёт.
4. **Готовится** — система автоматически сопоставляет колонки (дата/SKU/количество), проверяет и приводит данные к единому виду.
5. **Обработан** — готово: видны количество строк и SKU и предпросмотр. Если файл был нацелен на датасет, он вливается в него с отчётом «+N · заменено M».
6. **Ошибка** — что-то не так с файлом; показывается понятное сообщение о причине (см. статью «Сообщения об ошибках подготовки файла»). Исправьте файл и загрузите заново.

Цвета статусов: серый — в процессе/ждёт действия, зелёный — успех, красный — ошибка.
