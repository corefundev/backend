# Что такое Sprosly и кому он подходит

**Sprosly — платформа машинного обучения для прогноза спроса по SKU** для розницы и e-commerce. Вы загружаете историю продаж — получаете прогнозы спроса по дням с метриками качества. Без собственного аналитика и без своей ML-инфраструктуры.

## Возможности

- **Высокая точность** — ансамбль моделей машинного обучения с учётом сезонности и календаря праздников; метрики качества (WMAPE / MASE) в каждом прогнозе.
- **Быстрый старт** — от загрузки CSV до готового прогноза около 5 минут; без настройки гиперпараметров и без сервера.
- **API и веб-кабинет** — работайте через интерфейс или интегрируйте прогнозы в свой процесс через REST API; рекомендации к заказу выгружаются в CSV (формат для 1С).
- **Форматы данных** — загрузка CSV / Excel.
- **Вероятностные прогнозы** — интервалы p10 / p50 / p90, а не только одно число.

## Кому подходит

- **Сетям магазинов (розница)** — прогнозы по магазинам и регионам для оптимизации закупок.
- **Маркетплейсам и интернет-магазинам (e-commerce)** — дневной прогноз спроса с учётом промо, акций и сезонности для планирования остатков.
- **Производству и опту (B2B)** — прогноз отгрузок по контрагентам, планирование производства, снижение излишков.

## Как начать

Регистрация бесплатна и не требует карты: на тарифе Free доступно 30 SKU и горизонт 7 дней — можно оценить качество прогнозов на своих данных без обязательств. Начните на странице «Начать бесплатно», затем загрузите CSV с историей продаж.
