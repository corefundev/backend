# Безопасность ваших данных

## Изоляция

Данные каждого клиента хранятся и обрабатываются изолированно. Модель, обученная на вашей истории, доступна только вам.

## Проверки

Каждый загруженный файл проходит антивирусную проверку до любой обработки. Административные действия с данными фиксируются в защищённом журнале аудита.

## Резервные копии

Резервное копирование выполняется автоматически и регулярно, копии хранятся вне основного сервера. Свежесть бэкапов контролируется мониторингом круглосуточно.

## Чего мы не делаем

- не передаём ваши данные третьим лицам;
- не используем вашу историю для обучения моделей других клиентов;
- не запрашиваем персональные данные ваших покупателей — для прогноза они не нужны.
