# Глоссарий: Версия данных

**Версия данных** — «снимок» истории продаж датасета после очередного изменения. Каждая докладка файла (или удаление файла из датасета) создаёт новую версию: v1, v2, v3…

По каждой версии видно период данных, количество строк и SKU и отчёт слияния («+N · заменено M»). Модель обучается на конкретной версии; если после обучения появилась более новая версия, сервис покажет «данные новее модели» и предложит переобучить.
