# Как читать прогноз

## Что вы видите

В разделе «Прогнозы» для каждого SKU показан ожидаемый спрос на будущие дни. Прогноз — это оценка **среднего ожидаемого** спроса, а не гарантия: реальные продажи будут колебаться вокруг него.

## Как пользоваться

- для **закупок** суммируйте прогноз на срок поставки;
- для **планирования** смотрите агрегаты по неделям — дневные колебания сглаживаются;
- у товаров с редкими продажами прогноз по дням выглядит «дробным» (0.3 шт/день) — это нормально: суммируйте на неделю или месяц.

## Почему прогноз меняется

После каждого обучения модель перестраивается на свежей истории — прогноз обновляется. Это ожидаемое поведение: модель учитывает новые продажи.
