# Датасеты: именованные наборы данных, версии, докладка файлов и правило «новый файл побеждает»

**Датасет** — именованный набор данных о продажах со своей моделью и своими прогнозами. Например, отдельные датасеты для разных магазинов или направлений. Количество датасетов зависит от тарифа: Free — 1, Start — 3, Business — 10.

## Создание и датасет «Основной»

- Датасет создаётся кнопкой «+ Создать датасет»; имя — до 80 символов, уникальное в рамках аккаунта.
- Если вы уже загружали данные до появления датасетов, сервис автоматически создаёт датасет «Основной» с вашей последней обработанной загрузкой.
- При превышении лимита появится сообщение «Лимит датасетов вашего тарифа — N. Удалите неиспользуемый или повысьте тариф».

## Докладка файлов и правило слияния

В датасет можно докладывать новые файлы (кнопка «Доложить CSV»). Прикрепить можно только файл, прошедший подготовку.

Правило слияния: **если новый файл пересекается с уже загруженной историей по паре «SKU + дата», побеждает новый файл**. Это даёт бесплатные ретро-исправления: чтобы исправить ошибочный месяц, просто перезагрузите его исправленный файл — пересекающиеся дни будут заменены.

После каждой докладки показывается отчёт вида **«+N · заменено M»**: N строк добавлено, M строк заменено новыми значениями. Если внутри одного файла есть дубли «SKU + дата», берётся последняя строка файла.

## Версии данных

Каждая докладка (или удаление файла) создаёт новую **версию данных** датасета: v1, v2, v3… По каждой версии видно период данных, количество строк и SKU, отчёт слияния и дату создания.

## Данные и модель

- Модель обучается кнопкой **«Обучить модель»** — всегда на текущей (последней) версии данных. Автоматического переобучения нет.
- Если данные обновились после последнего обучения, на странице датасета появится предупреждение «данные новее модели» с кнопкой «Обучить на vN» — прогнозы продолжают строиться старой моделью, пока вы не переобучите.
- Если в датасете ещё нет данных, при попытке обучения появится сообщение «В датасете ещё нет данных — доложите файл».

## Удаление

- Файл можно убрать из датасета — данные датасета пересоберутся без него (новая версия).
- Датасет можно удалить целиком.
