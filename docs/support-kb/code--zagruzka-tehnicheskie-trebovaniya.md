# Технические требования к загрузке файлов: форматы, размер, статусы обработки

## Форматы и размер

- Принимаются файлы **CSV (.csv)** и **Excel (.xlsx)**.
- Максимальный размер файла — **50 МБ**.
- Пустой файл не принимается.
- Старый формат Excel **.xls не поддерживается** — откройте файл в Excel и сохраните как .xlsx (или CSV).
- Файлы Excel с макросами (**.xlsm**) не принимаются — сохраните как обычный .xlsx (макросы для прогноза не нужны).

## Путь файла после загрузки

1. **Загрузка** — файл принят, начинается проверка.
2. **Антивирусная проверка** — автоматически, занимает секунды. Если найдена угроза, файл удаляется, вы увидите сообщение «Файл не прошёл проверку безопасности и был удалён».
3. **Файл проверен** — дальше он сам никуда не идёт: нажмите кнопку **«Подготовить»**.
4. **Подготовка** — система автоматически сопоставляет колонки (дата, товар, продажи), проверяет данные и приводит их к единому виду. Сопоставление колонок вручную не редактируется.
5. **Обработан** — файл готов: видно количество строк и SKU, доступен предпросмотр, файл можно докладывать в датасет и использовать для обучения.

Если на любом этапе возникла ошибка, у файла появится статус ошибки и понятное сообщение о причине. При временной технической ошибке появится сообщение «Временная ошибка обработки. Попробуйте ещё раз позже» — просто повторите загрузку позже.

## Загрузка сразу в датасет

При загрузке файла можно сразу указать датасет — после успешной подготовки файл автоматически прикрепится к нему (в интерфейсе это кнопка «Доложить CSV» на странице датасета). Пока файл готовится, он отображается в таблице файлов датасета со статусом «Ждёт подготовки».

## Отмена загрузки

Загрузку можно удалить в любой момент — файл и связанные с ним данные будут удалены из хранилища.

## Обучение — только на подготовленных данных

Запустить обучение можно только на данных, прошедших подготовку. Прикрепить к датасету можно только обработанный файл: если файл ещё не готов, появится сообщение «Файл ещё не обработан. Дождитесь подготовки».
