# Глоссарий: Подготовка данных

**Подготовка данных** — шаг между загрузкой файла и его использованием. После антивирусной проверки вы нажимаете кнопку «Подготовить», и система автоматически определяет, какая колонка — дата, какая — SKU, какая — количество, проверяет данные и приводит их к единому виду.

Сопоставление колонок вручную не редактируется — оно детерминировано и одинаково для всех. Результат виден в предпросмотре; готовые подготовки собираются в «Истории подготовок». Обучать модель можно только на подготовленных данных.
