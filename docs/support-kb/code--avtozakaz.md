# Автозаказ: рекомендации к заказу, уровень сервиса, страховой запас и выгрузка для 1С

Раздел «Автозаказ» считает по каждому SKU рекомендуемое количество к заказу на период закупки.

## Формула заказа

**Заказ = прогноз спроса + страховой запас − остаток**

- **Прогноз спроса** — сумма точечного прогноза за окно заказа (по умолчанию 14 дней; можно выбрать от 1 до 60 дней).
- **Страховой запас** — надбавка «на всякий случай», рассчитанная из доверительного диапазона прогноза (p10–p90) под выбранный уровень сервиса.
- **Остаток** — последний известный остаток из колонки `stock` ваших данных. Если колонки остатков в данных нет, в таблице остаток показывается как «—» и из заказа ничего не вычитается.

Итоговое количество к заказу не бывает отрицательным и округляется **вверх** до целых штук — это безопасный запас.

## Уровень сервиса

Уровень сервиса определяет, насколько сильно вы страхуетесь от дефицита:

- Диапазон значений — от 0.5 до 0.95; значение по умолчанию — 0.7.
- Чем выше уровень сервиса, тем больше страховой запас: выбирайте выше, если дефицит для вас дороже хранения (в интерфейсе слайдер показывает соотношение «дефицит дороже хранения N:1»).
- Менять уровень сервиса можно на платных тарифах (Start и Business); на Free действует стандартное значение.
- Смена уровня сервиса пересчитывает рекомендации **сразу, без переобучения модели**.

## Дни без рекомендации

Рекомендация строится по дням, для которых у модели есть откалиброванный доверительный диапазон. Для дальних дней горизонта диапазон может отсутствовать — такие дни не входят в рекомендацию. В таблице это видно по колонкам «дней в окне» и «дней с рекомендацией»: если они различаются, рекомендация покрывает не всё окно.

## Выгрузка для 1С

Кнопка «Выгрузить заказ для 1С» скачивает CSV-файл:

- кодировка UTF-8 с BOM (корректно открывается в Excel и 1С);
- разделитель — точка с запятой «;»;
- колонки: SKU; Остаток; Спрос (прогноз); Страховой запас; К заказу; Мин (p10); Макс (p90); Дней в окне; Дней с рекомендацией;
- количество к заказу округлено вверх до штук.

Если прогнозов ещё нет, выгрузка недоступна — сначала обучите модель.
