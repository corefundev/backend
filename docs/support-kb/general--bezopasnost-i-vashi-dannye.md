# Ваши данные в Sprosly: хранение, изоляция, экспорт и удаление

## Где и как хранятся данные

Данные хранятся и обрабатываются в российском контуре — на серверах в РФ. Передача данных идёт по HTTPS, при хранении используется шифрование на диске. Резервное копирование выполняется автоматически и регулярно, копии хранятся вне основного сервера, их свежесть контролируется мониторингом круглосуточно.

## Изоляция

Данные каждого клиента изолированы. Модель, обученная на вашей истории, доступна только вам; ваша история **не используется** для обучения моделей других клиентов и не передаётся третьим лицам.

## Что мы храним

- Email (для входа и уведомлений) и хеш пароля (сам пароль не хранится).
- Загруженные файлы продаж и построенные на них датасеты, модели и прогнозы.
- Историю обучений и журнал действий с аккаунтом.

Персональные данные ваших покупателей для прогноза не нужны — мы их не запрашиваем. Каждый загружаемый файл проходит антивирусную проверку до любой обработки.

## Экспорт своих данных

Вы можете в любой момент запросить выгрузку всех данных, которые сервис хранит о вашем аккаунте (профиль, история загрузок, история обучений, журнал доступа) — самостоятельно через API или обращением в поддержку.

## Удаление аккаунта и данных (право на забвение, 152-ФЗ)

Аккаунт можно закрыть самостоятельно. При закрытии:

1. Доступ к аккаунту прекращается **немедленно** (включая активные сессии).
2. В течение срока хранения (стандартно 30 дней) данные ещё можно восстановить обращением в поддержку — на случай ошибочного закрытия.
3. По истечении срока персональные данные удаляются безвозвратно.

Сообщение сервиса при закрытии: «Аккаунт закрыт. Доступ прекращён; персональные данные будут удалены по истечении срока хранения». Если что-то не получается — напишите в поддержку: dochub.org@gmail.com.
