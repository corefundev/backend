# Как посмотреть прогноз

1. Откройте раздел **Прогнозы** и выберите датасет.
2. Выберите окно суммирования — 7 / 14 / 28 дней (28 дней — на тарифе Business).
3. Сверху — итоги: сумма прогноза, точность для заказа, используемая модель.
4. В таблице по каждому SKU: прогноз на завтра, суммы за 7 и 14 дней, диапазон p10–p90 и динамика («+6% к прошлой неделе», «стабильно», «всплеск»). Сортируйте по вкладу в сумму, чтобы видеть самые значимые товары.

Прогнозы пересчитываются автоматически после каждого успешного обучения — отдельно ничего запускать не нужно. Помните: точечное значение — это средний ожидаемый спрос; для решений о заказе смотрите на сумму за период и диапазон p10–p90.
