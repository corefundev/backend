# Первая загрузка данных: пошагово

Чтобы начать работать с сервисом, нужно загрузить файл с историей продаж. Вот пошаговая инструкция.

## Шаг 1. Подготовьте файл

Сервис работает с файлами в формате CSV (значения, разделённые запятыми). Это стандартный формат для таблиц.

Откройте 1С (или другую систему учёта) и выгрузите продажи в CSV:

- **Дата** — когда была продажа (например, 2025-01-15)
- **Товар (SKU)** — уникальный код товара (например, артикул)
- **Количество продано** — сколько единиц было продано (число)

Опционально можно добавить:

- Цену товара в этот день
- Был ли промо (акция)
- Остаток на полке

Подробнее о формате см. в статье [«Формат CSV: обязательные колонки date/sku/sales, опциональные price/promo/stock»](/help/a/csv-format).

История должна быть как можно длиннее — минимум несколько месяцев для хороших прогнозов.

## Шаг 2. Загрузите файл

В сервисе перейдите в раздел **Данные** → **Загрузить файл**.

1. Нажмите на поле загрузки или выберите файл через проводник
2. Выберите CSV-файл со своего компьютера
3. Нажмите **Загрузить**

Файл загрузится и сразу проверится на вирусы. Обычно это занимает несколько секунд. После этого вы увидите кнопку **Подготовить**.

## Шаг 3. Подготовьте данные

После проверки файла нажмите **Подготовить**. Система сама определит, какая колонка — дата, какая — SKU, какая — количество (даже если они названы иначе: `Date`, `Дата`, `артикул` и т.п.), и приведёт данные к единому виду.

Когда подготовка завершится, вы увидите предпросмотр результата. Проверьте, что данные выглядят корректно:

- Даты в правильном формате
- SKU не потеряны или не повреждены
- Количество — это числа, а не текст

Сопоставление колонок вручную не редактируется: если система поняла файл неверно, поправьте заголовки в исходном файле и загрузите его заново.

## Шаг 4. Ошибки (если они есть)

Сервис проверит данные и покажет, если есть проблемы:

- Пустые ячейки в обязательных колонках
- Невалидные даты
- Дублирующиеся строки (одна дата + один товар два раза)

Если есть ошибки, исправьте их в исходном файле и загрузите ещё раз. Обычно это выгрузка из 1С, коррекция в Excel, и снова загрузка.

## Шаг 5. Версия данных

После успешной подготовки файл становится **версией данных**. Каждый загруженный файл — это новая версия. Сервис сравнивает версии и говорит, что добавилось нового, а что изменилось.

На странице **Данные** вы видите список всех версий с информацией:

- Когда загружена
- Сколько дней покрывает
- Статус (готова, в обработке, ошибка)

## Шаг 6. Обучение модели

Как только данные подготовлены, сервис может обучить модель. Перейдите в раздел **Прогнозы** и нажмите кнопку **Обучить**.

Обучение — это автоматический процесс, где модель ищет закономерности в ваших продажах. Это может занять несколько минут, в зависимости от объёма данных.

Когда обучение завершено, вы увидите первый прогноз.

## Что дальше

Теперь у вас есть первый прогноз. Посмотрите на рекомендуемый заказ и решите, заказать ли по рекомендации.

Когда придут реальные продажи за новые дни, загрузите их в сервис. Модель пересчитается и прогноз уточнится.

Не ждите идеальной точности сразу — с каждым месяцем данных модель становится лучше.
