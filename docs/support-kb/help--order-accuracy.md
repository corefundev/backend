# «Точность для заказа» и дневная точность: почему заказ на период точнее

Сервис показывает две разные точности: для дневных прогнозов и для итогового прогноза на неделю/месяц. Почему одна лучше другой?

## Два вида точности

**Дневная точность** — насколько точен прогноз на один день

```
Завтра: 25 единиц (±6)
Точность: MAPE 24%
```

Это означает: каждый отдельный день прогноз ошибается в среднем на 24%.

**Точность для заказа (сумма за период)** — насколько точен прогноз на неделю/месяц

```
За неделю: 175 единиц (±15)
Точность: MAPE 9%
```

Это означает: прогноз суммы за неделю ошибается в среднем на 9%.

Разница поразительна! Сумма точнее почти в 3 раза (24% vs 9%).

## Почему это происходит

Когда вы складываете много дней, случайные ошибки гасят друг друга.

**Пример:**

Истинный спрос по дням:

```
Пн: 20
Вт: 25
Ср: 22
Чт: 23
Пт: 30
Сб: 18
Вс: 17
Итого: 155
```

Прогноз модели по дням:

```
Пн: 23 (ошибка +3)
Вт: 24 (ошибка −1)
Ср: 20 (ошибка −2)
Чт: 25 (ошибка +2)
Пт: 29 (ошибка −1)
Сб: 21 (ошибка +3)
Вс: 16 (ошибка −1)
Прогноз суммы: 158
Истинная сумма: 155
Ошибка суммы: +3 (только 2%)
```

Посмотрите: дневные ошибки скачут туда-сюда (от −2 до +3), но когда мы их складываем, они в основном взаимно компенсируются.

Это математический факт: при складывании независимых случайных величин результирующая ошибка меньше.

## Применение на практике

Если вы закупаетесь еженедельно:

- **Используйте прогноз на неделю (сумма)** — он точнее
- Не полагайтесь на посуточный прогноз
- Заказывайте по еженедельной рекомендации

Пример:

```
Неделя 1: прогноз 170 ± 15 (точность 8%)
Дни: 24, 25, 26, 24, 25, 23, 23 (точность 22% посуточная)
→ Заказывайте 170–180 (в зависимости от запаса)
```

Если вы закупаетесь ежедневно:

- **Используйте дневной прогноз** — это всё, что есть
- Понимайте, что он менее точен (±24%)
- Добавьте страховку в виде запаса

## Месячные прогнозы ещё точнее

На месячный горизонт точность ещё выше, потому что в месяце больше дней, а ошибки гасятся сильнее.

```
Месячный прогноз: MAPE 5% (ошибка ±5%)
Недельный прогноз: MAPE 9% (ошибка ±9%)
Дневной прогноз: MAPE 24% (ошибка ±24%)
```

## Запас безопасности

Это полезная информация для выбора запаса:

**Если закупаете на неделю:**

```
Точность: 9%
Запас: 9% × точечный прогноз = запас на одну стандартную ошибку
```

**Если закупаете ежедневно:**

```
Точность: 24%
Запас: 24% × точечный прогноз = запас на одну стандартную ошибку
```

Если вы хотите избежать дефицита 95% времени, нужен больший запас для ежедневных заказов.

## Математическое объяснение (если интересно)

Если ошибка каждого дня случайна и независима, и стандартная ошибка дня = σ, то:

- Ошибка суммы 7 дней ≈ σ × √7 ≈ σ × 2.6

То есть абсолютная ошибка суммы почти в 2.6 раза больше, чем дневная. Но в процентах (MAPE) это гораздо меньше, потому что сама сумма в 7 раз больше дневного прогноза.

## Когда это не работает

Усреднение помогает, если ошибки случайны. Но если в данных **смещение** (систематическая ошибка в одну сторону), оно не компенсируется.

Например, если модель всегда недооценивает спрос на 10%, то:

- Дневная ошибка: −10%
- Недельная ошибка: всё ещё −10% (не гасится)

Это признак, что модель нужно переобучить.

## Совет

- Закупаетесь раз в неделю? Смотрите на недельный прогноз, доверяйте ему больше, чем посуточным
- Закупаетесь ежедневно? Признайте, что точность ниже, добавьте больше запаса
- Если возможно, переходите на недельные/двухнедельные циклы закупок — так экономнее и надёжнее
